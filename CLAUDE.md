## Project Overview

Static website for Kuska Autism Services (kuska.co) — ABA therapy and autism evaluations in Bountiful & Draper, Utah. The site was migrated from WordPress to flat HTML and is deployed to Netlify (`netlify.toml` publishes the `kuska-website/` directory).

## Running the Site

```bash
cd kuska-website && python3 -m http.server 8000
```

## Architecture

```
kuska-website/           # Deploy root (published to Netlify)
├── index.html           # Homepage
├── <page-slug>/index.html   # One directory per page/blog post (~28 pages)
├── site.css             # All styles (~930 lines)
├── site.js              # Mobile nav toggle + footer year
├── 404.html             # Netlify custom 404
├── sitemap.xml / robots.txt
├── _redirects           # Netlify redirects (old /blog/<slug>/ URLs → /<slug>/)
├── feed/                # Static RSS feed snapshot (contains post body copies)
└── wp-content/uploads/  # Image assets (paths kept from WordPress migration)
scripts/
├── build_custom_site.py   # Original generator that produced the pages
├── migrate_wordpress.py   # WordPress content extraction
└── mirror_live_site.py    # Mirrored the old live site
```

### Important: pages are hand-maintained now

The HTML pages were originally generated by `scripts/build_custom_site.py`, but they have since been hand-edited directly (see git history — homepage hero, About page layout, link fixes). **Do not re-run the build script**; it would clobber those manual changes. Edit the HTML files in place.

When editing blog post content, note the same copy may also exist in `feed/index.html` (the RSS snapshot) — update both if it matters.

### Conventions

- Brand colors: Kuska Blue `#3989c9`, Kuska Yellow `#ebc94e` (see `site.css` custom properties)
- Fonts: Montserrat / Montserrat Alternates via Google Fonts
- Shared header/footer markup is duplicated in every page — a change to nav or footer must be applied to all `index.html` files (and `404.html`)
- Image paths keep the `/wp-content/uploads/...` structure so URLs from the WordPress era keep resolving
- Contact/Get Started pages embed Zoho forms via iframes; there are no native HTML forms
- Business facts: phone (801) 980-7970, email admin@kuska.co, locations 95 2200 S Bountiful UT 84010 and 12055 S 700 E Draper UT 84020 (also in JSON-LD on every page)

### Adding a page or post

1. Create `<slug>/index.html`, copying the head/header/footer shell from an existing page (update `<title>`, meta description, canonical, `og:` tags, and `data-page`)
2. Add the URL to `sitemap.xml`
3. For blog posts: add a card to `blog/index.html`
